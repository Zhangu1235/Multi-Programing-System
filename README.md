📌 Features
⚙️ Process Management
Create, pause, resume, and terminate processes

Dynamic process handling with PID allocation

Supports different process types and priorities


🧠 Scheduling Algorithms

Implemented multiple CPU scheduling algorithms:

Round Robin (RR)

Priority Scheduling

Shortest Job First (SJF)


💾 Memory Management
Paging-based memory allocation

Waiting queue for insufficient memory conditions

Automatic memory reclamation during overload


📊 Real-Time Monitoring
Live CPU and memory utilization graphs

Real-time process updates using WebSocket

System activity logs and status indicators

🔄 Dynamic Resource Allocation
Detects CPU and memory overload conditions

Automatically adjusts system behavior for optimization
